# Лаба 5 — Хранилища данных в облаке (Block, File, Object: выбор и применение)

Продолжение проекта интернет-магазина «Пальчики оближешь» из Лаб 1–4. **Цель:** спроектировать размещение разных видов данных в подходящих облачных хранилищах и обосновать выбор по задержке, совместному доступу, устойчивости и стоимости.

**Формат работы:** проектирование; AWS-ресурсы в этой лабораторной не развёртывались. На существующем домашнем стенде в Лабе 6 уже проверялась репликация PostgreSQL primary/standby; это отдельная практическая работа.

## Принятые решения

| Данные | Сервис |
|---|---|
| Сайт и изображения товаров | S3 Standard + CloudFront |
| Диски API-серверов | EBS gp3 |
| PostgreSQL (primary/standby) | EBS io2 в разных AZ |
| Общий каталог файлов | EFS Regional (NFS) |
| Бэкапы и длительное хранение | S3 Standard → Standard-IA → Glacier Flexible Retrieval → Deep Archive |

В отчёте есть сравнительные таблицы Block/File/Object, аналоги провайдеров, схема Mermaid, политика резервного копирования и восстановления, безопасность, чек-лист и ответы на контрольные вопросы.

**Основной документ:** [report.md](report.md).

**Как посмотреть схему:** GitHub отображает Mermaid прямо в `report.md`. Для отдельного SVG можно открыть диаграмму в Mermaid Live Editor и экспортировать её.
